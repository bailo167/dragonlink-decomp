# The per-game report

One report per recovered game, version and platform, generated by

```sh
dragonlink-analyze analyze-game <configuration> --simulate 3000000 --seed 7
```

The generator is `crates/dragonlink-math/src/report.rs`. A section whose content is not known says
"unknown"; nothing is filled in to look complete. A report on the synthetic fixture begins with a
banner saying that none of it describes a Dragon Link game.

A report on a recovered configuration is written next to that configuration in the private source
root, not into the repository ([../../DECISIONS.md](../../DECISIONS.md), D-010).

## Sections

| Section | Content | Source of the numbers |
|---|---|---|
| **Game / version / platform** | Title and the banner stating what kind of configuration this is. | configuration |
| **Configuration identity** | Title, market, platform, program version, regulatory specification, denomination, model id. | configuration |
| **Evidence confidence** | Model provenance and the tally of constants by provenance class. | configuration |
| **Reel model** | Window, number of stop combinations, per reel: stops and symbol counts. | configuration |
| **Pay table** | Every paying line outcome with its pay, probability per line and share of return. | exact |
| **RTP** | Return by component: lines (as an exact fraction), scatters, feature credit prizes, each jackpot level; total. | exact |
| **Hit frequency** | Per-line hit probability; whole-spin hit frequency, base-game variance and largest award. | exact; enumeration when tractable |
| **Feature frequency / feature EV** | Trigger probability, distribution of the starting and final orb counts, expected respins, value given trigger. | exact recursion |
| **Jackpot model** | Per level: value, expected awards per spin, frequency, share of return. | exact |
| **Progressive contribution** | Meter increments and contribution rates. | not modelled yet; stated as such |
| **Overall EV** | Total return, expected result per spin, return excluding jackpot levels. | exact |
| **Denomination effects / bet effects** | What the bet changes within this configuration; pointer to comparison for denominations. | configuration; `compare-games` |
| **State dependence · RNG architecture · outcome-selection timing** | The configuration's behaviour findings, each with its confidence, or "unknown". | configuration |
| **Known version differences** | Differences from other versions. | `compare-games` |
| **Unknowns** | Everything not established or not modelled. | configuration and model limits |
| **Evidence / provenance** | One row per constant: provenance class, source, note. | configuration |
| **Validation results** | Exact figures against a seeded simulation of our implementation, with intervals; and against captured gameplay of the original, when captures exist. | simulation; captures |

## Related outputs

- `dragonlink-analyze compare-games <a> <b>`: a verdict (identical, prize scaling only, or more),
  the differing constants, and the main quantities side by side.
- `dragonlink-analyze progressive-ev <configuration> --meter grand=<credits> …`: return at the given
  meter values and the break-even meter of each level.
- `--json` on each gives the same content for further processing.
